2. Какие данные мы собираем

В рамках предоставления сервиса электронных карт лояльности собираются только минимально необходимые данные:

  • Номер телефона: используется как основной идентификатор гостя в ресторанной системе iiko Cloud и для привязки карты в Google/Apple Wallet.
  • Имя и фамилия (по желанию): для персонализации обращения к гостю на лицевой стороне карты лояльности.
  • Дата рождения (по желанию): исключительно для автоматического начисления праздничных бонусов и поздравлений от заведения.
  • Баланс бонусов и номер карты: учет количества накопленных баллов и скидок в кассовой системе заведения.
  • Технические идентификаторы: обезличенные токены объектов Google Wallet Object ID и Apple PassKit Serial Number для доставки обновлений баланса на смартфон.

3. Цели сбора и использования информации

Персональные данные используются исключительно для следующих целей:

  • Выпуск и отображение персональной карты лояльности в приложениях Google Wallet и Apple Wallet;
  • Идентификация гостя при сканировании QR-кода карты на кассе ресторана (iiko);
  • Отображение актуального баланса баллов и истории операций;
  • Информирование гостя через Telegram/WhatsApp о начислении или сгорании бонусов (только при наличии согласия гостя);
  • Техническая поддержка пользователей.

4. Передача данных третьим лицам

Сервис MadiTech ни при каких обстоятельствах не продает, не сдает в аренду и не передает персональные данные третьим лицам для рекламных целей.

Данные передаются исключительно защищенным техническим партнерам, необходимым для функционирования сервиса:

  • Google LLC (Google Wallet API): для генерации ссылки сохранения карты и обновления баланса на устройствах Android;
  • Apple Inc. (Apple Developer / PassKit): для доставки файла .pkpass и Push-уведомлений на устройства iOS;
  • iiko Cloud (iiko Transport): кассовая учетная система ресторана для подтверждения прав на скидку или бонус.

5. Безопасность и хранение данных

Все данные передаются исключительно с использованием современных криптографических протоколов TLS 1.3 / HTTPS. Серверная инфраструктура защищена строгими политиками разграничения доступа, токены авторизации хранятся в зашифрованном виде.
